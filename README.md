# 4d4-privacy

Политика конфиденциальности приложения **4D4 Generator** (`com.vitvit.generator4d4`)
для Google Play. Репозиторий существует только ради публичной страницы.

Страница: https://udrishvit-vit.github.io/4d4-privacy/

Исходник — один файл `index.html`, на трёх языках: русский, английский, испанский.
Публикуется через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

При изменениях в приложении (появятся разрешения, аналитика, сетевые запросы) страницу
нужно обновить — и здесь, и в исходнике `docs/index.html` проекта 4d4-generator.
